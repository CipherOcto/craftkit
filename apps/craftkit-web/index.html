craftkit did not start

This page needs WebAssembly and WebGL2. The usual causes, in the order they are worth checking: 

1. The bundle is missing.        Run:  cargo xtask bundle
2. The wasm-bindgen CLI version does not match the wasm-bindgen crate.
3. The page was opened over file://, which has no origin for localStorage.
4. WebGL2 is disabled in this browser or by a GPU blocklist.
5. It is being served with a MIME type other than application/wasm.

The real reason is in the browser console, and it is the only place it appears — which is why this box exists.
