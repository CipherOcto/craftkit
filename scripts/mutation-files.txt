# The files a mutation may write to.
#
# This is the contract between the script and the restore: a mutation to a
# file that is not on this list cannot be put back, and the script's `guarded`
# refuses it. The gate `cargo xtask anchors` reads this file too, so the list
# lives in one place and both doors read it.
#
# The script reads it rather than carrying it, because a list inside a script
# cannot be broken: bash reads a script as it goes, so a case cannot edit the
# script it is running. A file that is read is a file that can be mutated, and
# a mutation of this list is a mutation of the contract. Section 187.
#
# One path per line, relative to the repository root. A blank line, a
# duplicate, or a path that is not in the tree is reported by the gate.
